# Islamic Studies at MCCT (Webpage)

A simple webpage that lists videos from the **MCCT Tucson** YouTube channel (last 6 months + future uploads), supports time-of-day filtering (morning/afternoon/evening), and provides:

- Link to each video
- A short **AI-generated title** derived from transcript summary
- High-level **topic categorization** (Quran, Hadith, Riyadh as-Salihin, Al-Wajeez, etc.)

## What’s implemented

- Static site (Vite) suitable for **GitHub Pages**.
- UI filters: date range, time-of-day (morning/afternoon/evening), and topic.
- Data model expects `public/videos.json` generated by a script.

## Option A (recommended): GitHub Actions generates videos.json

Because GitHub Pages is static, we keep the YouTube API key out of the browser.

1. Create a GitHub repo and push this project.
2. In GitHub repo settings → **Secrets and variables** → **Actions** → create secret:
   - `YT_API_KEY` = your YouTube Data API v3 key
3. In repo settings → **Pages**:
   - Source: **GitHub Actions**
4. Workflows included:
   - `.github/workflows/update-videos.yml` (daily + manual) updates `public/videos.json`
   - `.github/workflows/deploy-pages.yml` builds and deploys the site

## Notes

- Current “AI title” is a cleaned version of the YouTube title. Next step is transcript-based summarization.
- Topic tagging is rule-based and can be expanded.
